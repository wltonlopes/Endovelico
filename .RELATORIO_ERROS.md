# Relatório de erros do mod Endovelico (26/09/2026)

Verificação feita com o próprio motor do 0 A.D. 0.29 (modo headless, carregando os 6320 templates e percorrendo tudo que é treinável/construível a partir das unidades iniciais de cada civ), mais uma varredura estática de todas as referências de arte (atores, meshes, texturas, ícones, variantes, materiais, músicas).

Resultado final no motor: **0 templates com erro de schema, 0 tecnologias inexistentes em Researcher, 0 erros no log.**

## O que foi corrigido

### Templates que o jogo rejeitava (unidade/prédio quebrado)
- `units/anish/infantry_clubman_merc`: `<Promotion disabled="">` → `disable=""`.
- `units/cyre/infantry_swordsman_a`: herdava de `infantry_swordsman_merc_b` (que desliga Promotion) — voltou a herdar de `infantry_swordsman_b` (mudança acidental no commit "fix zapotecs").

- Heróis/campeões/curandeiros sem rank (`khoi`, `nok`, `sonin` — 8 arquivos): adicionado `<Promotion disable=""/>` (o pai exigia `Promotion/Entity`).

   - Lista completa no apêndice.
10. **Scouts**: vários templates usam `parent="scout_mount_swordsman"` etc. apontando para mixins sem o prefixo `|`. O motor 0.29 aceita (validei), mas é um padrão fora do usual — se uma versão futura mudar isso, todos os scouts quebram.
